# @cratis/identity

Generated TypeScript proxies for [Cratis Identity](https://github.com/Cratis/Identity), built on `@cratis/arc`. The proxies are generated from the `Cratis.Identity` assembly during the .NET build.

This package is **unpublished** (`"private": true`) and ships no proxies yet: Identity has no Arc commands or queries. It is built and packed by CI as an artifact until the token contract (#24) and the first realm contract (#26) are locked.
